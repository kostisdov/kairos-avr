# KAIROS: deviations log

Design rule 0.6 of `kairos_azure_build_design.md`: scientific definitions are fixed; any
implementation detail that forces a deviation is recorded here and stops for review. Items
marked **scientific** touch a definition and need the owner's review before the artefacts
are presented as following the specification. Items marked **implementation** change no
definition.
